# Oli Whisper core

This directory contains the local Rust transcription engine used by Oli.

It wraps the current `whisper-rs` bindings to whisper.cpp. The crate exposes Metal and Core ML feature flags; the Core ML runtime uses the companion encoder artifact generated by whisper.cpp next to the GGML model. citeturn947919search2turn209481search0turn209481search5

## Build on Apple Silicon

    cargo build --release --manifest-path native/rust/whisper-core/Cargo.toml --features metal,coreml

For a portable CPU-only build:

    cargo build --release --manifest-path native/rust/whisper-core/Cargo.toml

## Model layout

Keep the GGML model and its Core ML encoder together:

    models/
      ggml-large-v3-turbo-q5_0.bin
      ggml-base.en-q5_0-encoder.mlmodelc/

whisper.cpp derives the Core ML encoder path by replacing the model extension and appending `-encoder.mlmodelc`. citeturn209481search0

Quantized models are supported by whisper.cpp; the repository documents `q5_0` quantization as an example. citeturn209481search5

## One-shot

    cargo run --release --manifest-path native/rust/whisper-core/Cargo.toml --features metal,coreml --       --model models/ggml-base.en-q5_0.bin       --audio samples/meeting.wav       --language en

The command prints one JSON object containing the full transcript and timestamped segments.

## Persistent stdio mode

Oli can keep one model resident and feed multiple short WAV chunks:

    native/rust/whisper-core/target/release/oli-whisper       --model /absolute/path/to/ggml-base.en-q5_0.bin       --stdio

Send:

    {"audio_path":"/absolute/path/to/chunk.wav","language":"en","threads":4}

Each request receives one JSON result line. No network connection is made by this process.
